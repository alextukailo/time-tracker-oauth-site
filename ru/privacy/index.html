Важная информация: расширение запрашивает разрешение на работу со всеми Google Таблицами аккаунта, но синхронизация предназначена для таблицы, которую вы подключаете сами.

Кто мы

Time Tracker («Трекер времени») — расширение Chrome для учёта времени по проектам с синхронизацией в Google Таблицы. Эта политика описывает работу версии расширения, использующей Google OAuth и Google Sheets API.

Контакт разработчика: SUPPORT_EMAIL_PLACEHOLDER.

Какие данные доступны

После вашего согласия Time Tracker получает OAuth-токен для доступа к Google Sheets API с разрешением https://www.googleapis.com/auth/spreadsheets. Это разрешение технически позволяет читать и изменять Google Таблицы, доступные вашему аккаунту, хотя функция синхронизации использует выбранную вами таблицу.

Расширение обрабатывает название и идентификатор выбранной таблицы, названия проектов, даты, время начала и окончания сессий, длительность, описания задач и технические идентификаторы записей для синхронизации.

Мы не запрашиваем ваш пароль Google.

Зачем используются данные

Данные используются исключительно для работы функций приложения: записи рабочего времени, отображения истории, синхронизации с выбранной таблицей, а также исправления и удаления записей по вашему запросу.

Google Sheets API используется для чтения и записи в подключённую таблицу. Данные не используются для рекламы, продажи данных или определения кредитоспособности.

Где хранятся данные

Проекты, сессии, настройки подключённой таблицы и очередь изменений хранятся локально в хранилище расширения Chrome (chrome.storage.local). Синхронизированные записи хранятся в подключённой вами Google Таблице в вашем Google-аккаунте.

Для OAuth используется Chrome Identity API; Time Tracker не сохраняет пароль Google. В текущей архитектуре расширение обращается к Google Sheets API напрямую и не использует собственный сервер для хранения ваших проектов или таблиц.

Передача данных

Time Tracker передаёт необходимые данные Google через Google Sheets API по HTTPS для выполнения запрошенной синхронизации. Разработчик не продаёт пользовательские данные, не передаёт их рекламным сетям и не предоставляет сторонним организациям для маркетинга.

Веб-сайт приложения может размещаться у внешнего хостинг-провайдера, который обрабатывает стандартные технические запросы согласно собственной политике. Сам сайт не содержит встроенной аналитики или рекламных трекеров.

Ограниченное использование Google API

Использование данных, полученных через Google API, осуществляется в соответствии с Google API Services User Data Policy и её требованиями Limited Use. Оно ограничено предоставлением функций Time Tracker, описанных в интерфейсе приложения.

Использование информации, полученной от Google API, также соответствует Chrome Web Store User Data Policy, включая требования Limited Use.

Доступ и удаление

Вы можете удалять сессии и проекты через интерфейс Time Tracker и изменять или удалять записи непосредственно в Google Таблице. Отключение аккаунта либо удаление расширения не удаляет автоматически содержимое вашей таблицы.

Разрешение Google можно отозвать на странице Google Account — Connections. Чтобы удалить локальные данные, необходимо очистить данные расширения или удалить его из Chrome. Для очистки данных, уже сохранённых в таблице, удалите соответствующие строки или саму таблицу в Google Sheets.

Безопасность

Связь с Google Sheets API выполняется по HTTPS. Доступ к таблицам определяется разрешениями Google-аккаунта и выданным OAuth-доступом. Не предоставляйте приложению доступ к таблицам, которые не хотите использовать для учёта времени.

Изменения политики

При изменении способов обработки данных мы обновим эту политику и дату её действия. Существенные изменения, требующие дополнительного согласия, будут обозначены в продукте до применения.
